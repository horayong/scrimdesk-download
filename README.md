# ScrimDesk 다운로드

친구들끼리 하는 리그 오브 레전드·발로란트 내전(5:5 커스텀 게임) 기록 앱 ScrimDesk의 배포용 저장소예요.
이 저장소에는 앱 파일만 올라가요.

## 받기

**[최신 버전 받기 (ScrimDesk.zip)](https://github.com/horayong/scrimdesk-download/releases/latest/download/ScrimDesk.zip)**

예전 버전과 바뀐 점은 [릴리스 목록](https://github.com/horayong/scrimdesk-download/releases)에서 볼 수 있어요.

## 설치

1. 받은 `ScrimDesk.zip`을 원하는 폴더에 **압축 풀기** 하세요. 압축 파일 안에서 바로 실행하면 안 돼요.
2. `ScrimDesk` 폴더 안의 `ScrimDesk.exe`를 실행하세요. 따로 설치할 것은 없어요(.NET 포함).
3. "Windows의 PC 보호" 창이 뜨면 **[추가 정보] → [실행]** 을 누르세요. 개인이 만든 앱이라 서명이 없어서 뜨는 안내예요.
4. 롤 또는 발로란트 런처(라이엇 클라이언트)에 로그인한 상태면 그 계정으로 자동 로그인돼요.

자세한 내용은 압축 안의 `사용법.txt`를 보세요.

## 새 버전으로 바꾸기

앱을 끄고, 예전 `ScrimDesk` 폴더를 지운 뒤 새로 받은 압축 파일을 같은 자리에 풀면 돼요.

서버는 운영자 PC에서 돌아가요. 운영자 PC가 꺼져 있으면 접속이 안 되니 운영자에게 물어보세요.
